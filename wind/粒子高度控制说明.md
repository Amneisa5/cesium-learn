# CanvasWindyHeight 粒子高度控制详解

## 🎯 控制粒子高度的关键位置

### 1️⃣ **第113行 - 核心高度计算** ⭐️⭐️⭐️

```javascript
particle.theight = particle.height + t * uvw[2];
```

**这是最关键的代码！** 它决定了粒子高度如何变化

- `particle.height`：粒子当前高度（单位：米）
- `t`：粒子移动所需时间（秒）
- `uvw[2]`：垂直风速（米/秒），这是控制高度的核心参数
- `particle.theight`：粒子下一步的高度

---

### 2️⃣ **第234行 - 初始高度设置**

```javascript
particle.height = Math.random() * 10000; // Random height between 0 and 10km
```

**作用：** 当粒子新生成或重生时，设置其初始高度（0-10公里）

---

### 3️⃣ **第37-48行 - 生成垂直风速数据**

```javascript
_addMockHeightData (json) {
  json.wdata = [];
  const total = json.rows * json.cols;
  for (let i = 0; i < total; i++) {
    // Mock vertical wind: random value between -5 and 5 m/s
    json.wdata.push((Math.random() - 0.5) * 10);
  }
}
```

**作用：** 
- 创建模拟的垂直风速数据
- 每个网格点有对应的垂直风速值
- 范围：-5 到 +5 米/秒
- `wdata` 数组长度 = 行数 × 列数

---

### 4️⃣ **第179-181行 - 风场向量计算**

```javascript
_calcUVW (u, v, w) {
  return [+u, +v, +w, Math.sqrt(u * u + v * v)]
}
```

**返回值的含义：**
- `uvw[0]`：东西方向风速 (u)
- `uvw[1]`：南北方向风速 (v)  
- `uvw[2]`：**垂直方向风速 (w)** ← 控制高度的关键
- `uvw[3]`：水平风速大小

---

### 5️⃣ **第108-113行 - 完整的高度更新流程**

```javascript
// 计算空间距离 (using Cesium)
let from = Cesium.Cartesian3.fromDegrees(particle.lng, particle.lat, 0);
let to = Cesium.Cartesian3.fromDegrees(particle.tlng, particle.tlat, 0);
let d = Cesium.Cartesian3.distance(from, to);  // 水平移动距离
let t = d / uvw[3];                             // 所需时间
particle.theight = particle.height + t * uvw[2]; // 新高度
```

**计算过程：**
1. 计算粒子水平移动距离 `d`
2. 计算移动所需时间 `t = d / 水平风速`
3. 计算新高度：`新高度 = 当前高度 + 时间 × 垂直风速`

---

### 6️⃣ **第127-153行 - 3D渲染时使用高度**

```javascript
// _tomap: 使用当前高度
_tomap (lng, lat, particle) {
  var ct3 = Cesium.Cartesian3.fromDegrees(lng, lat, particle.height)
  // 投影到屏幕...
}

// _tomap1: 使用下一步高度
_tomap1 (lng, lat, particle) {
  var ct3 = Cesium.Cartesian3.fromDegrees(lng, lat, particle.theight)
  // 投影到屏幕...
}
```

**作用：** 将粒子的3D位置（包含高度）投影到2D屏幕上，形成轨迹

## 📊 粒子高度变化的流程

```
初始化：
  particle.height = random(0, 10000)  ← 初始高度
  
每帧更新：
  1. 获取当前位置的风场数据 uvw = [u, v, w, speed]
  2. 计算水平移动距离 d
  3. 计算所需时间 t = d / speed
  4. 计算新高度：theight = height + t × w
  5. 更新粒子：height = theight
  
渲染：
  使用 particle.height 和 particle.theight 绘制轨迹线
```

## 🔧 如何调整粒子高度行为

### 修改初始高度范围
在 `CanvasWindyHeight.js` 第234行：
```javascript
// 当前：0-10km
particle.height = Math.random() * 10000;

// 改为0-20km
particle.height = Math.random() * 20000;

// 改为固定高度5km
particle.height = 5000;
```

### 修改垂直风速强度
在 `CanvasWindyHeight.js` 第44行：
```javascript
// 当前：-5 到 +5 m/s
json.wdata.push((Math.random() - 0.5) * 10);

// 增强上升气流：-10 到 +10 m/s
json.wdata.push((Math.random() - 0.5) * 20);

// 只允许上升：0 到 +8 m/s
json.wdata.push(Math.random() * 8);
```

### 调整移动速度（影响高度变化）
在 `index.js` 第106行：
```javascript
speedRate: 30000,  // 值越大，粒子移动越慢，高度变化越明显
```

## 🎨 视觉效果

- **垂直风速 > 0**：粒子上升，轨迹向上弯曲 ↗️
- **垂直风速 < 0**：粒子下降，轨迹向下弯曲 ↘️
- **垂直风速 = 0**：粒子保持同一高度，水平移动 →

---

## 💡 关键理解

**粒子高度的变化公式：**

```
Δ高度 = Δ时间 × 垂直风速

其中：
  Δ时间 = 水平移动距离 / 水平风速

因此：
  新高度 = 旧高度 + (水平距离 / 水平风速) × 垂直风速
```

**垂直风速来自哪里？**
- 从 `wdata` 数组中获取
- 通过双线性插值计算任意点的垂直风速
- 可以在 `_addMockHeightData` 函数中自定义生成

## 📝 数据结构

### 粒子对象（CanvasHeightParticle）
```javascript
{
  lng: 经度,
  lat: 纬度,
  height: 当前高度（米）⭐️,
  theight: 下一步高度（米）⭐️,
  age: 生命周期,
  speed: 水平风速,
  // ...
}
```

### 风场网格数据
```javascript
{
  xmin, xmax, ymin, ymax: 边界范围,
  rows, cols: 网格行列数,
  udata: 东西风速数组,
  vdata: 南北风速数组,
  wdata: 垂直风速数组 ⭐️ (控制高度)
}
```
