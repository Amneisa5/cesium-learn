# 风场数据图片说明

这个目录包含用于存储风场数据的图片文件。

## 文件说明

- `wind1.png`: 存储U分量（东西方向）的风场数据
- `wind2.png`: 存储V分量（南北方向）的风场数据

## 数据格式

- 图片的每个像素代表长江口区域的一个网格点
- 像素的R通道（红色）存储风场速度值
- 像素值范围：0-255
- 对应的风场速度范围：-10 到 +10 m/s
- 转换公式：`speed = (pixel_value / 255.0) * 20.0 - 10.0`

## 地理范围

- 经度：120°E - 123.5°E
- 纬度：30°N - 32.5°N
- 网格分辨率：0.1° × 0.1°

## 图片要求

- 格式：PNG
- 颜色模式：RGBA
- 建议尺寸：35 × 25 像素（对应3.5° × 2.5°的地理范围，0.1°分辨率）
