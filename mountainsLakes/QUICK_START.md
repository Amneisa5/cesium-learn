# 快速开始 - 地形与流场可视化

## 🚀 立即开始

1. **打开页面**
   ```
   打开 index.html
   ```

2. **等待加载**
   - 地形将首先加载并显示
   - 水位会在 5 秒内逐渐上升到海平面
   - 流场粒子系统会在地形加载完成后 1 秒启动

3. **使用控制面板**
   - 页面右上角会出现"🌊 流场控制"面板
   - 拖动滑块实时调整流场效果
   - 点击按钮显示/隐藏流场或重播水位动画

## 📊 效果说明

### 地形可视化
- **数据来源**: gebco_2023 GeoTIFF 高程数据
- **范围**: 120°E - 123.5°E, 30°N - 32.5°N
- **颜色映射**: 
  - 🟡 沙色: 低海拔
  - 🟢 绿色: 草地/森林
  - 🟤 棕色: 岩石/山地
  - ⚪ 白色: 积雪/冰川
  - 🔵 蓝色: 海洋区域（透明水体）

### 水位动画
- **动画时长**: 5 秒
- **效果**: 海水从海底逐渐上升到海平面（0米）
- **特点**: 
  - 使用缓动函数，开始和结束更平滑
  - 水体透明，可以看到海底地形
  - 水体颜色随深度变化

### 流场粒子
- **显示位置**: 地形上方 2000 米高度
- **粒子数量**: 16,384 个（128 × 128）
- **流场模式**: 旋涡 + 整体流动
- **颜色**: 根据速度大小显示（蓝色→黄色→红色）

## 🎮 控制说明

### 控制面板

#### 速度倍率 (0.0 - 5.0)
- **默认**: 1.0
- **推荐范围**: 0.5 - 2.0
- **效果**: 控制粒子移动速度
- **建议**: 
  - 慢速观察细节: 0.5
  - 快速查看流场: 2.0 - 3.0

#### 轨迹长度 (0.95 - 0.999)
- **默认**: 0.996
- **推荐范围**: 0.98 - 0.999
- **效果**: 控制粒子轨迹的衰减速度
- **建议**:
  - 短轨迹（清晰）: 0.95 - 0.98
  - 长轨迹（流畅）: 0.995 - 0.999

#### 线条宽度 (1.0 - 8.0)
- **默认**: 2.0
- **推荐范围**: 2.0 - 4.0
- **效果**: 控制粒子轨迹的线宽
- **建议**:
  - 细线（精细）: 1.0 - 2.0
  - 粗线（醒目）: 3.0 - 5.0

#### 按钮功能
- **隐藏/显示流场**: 切换流场粒子显示
- **重播水位动画**: 重新播放海水上升动画

### 鼠标操作（Cesium 标准）
- **左键拖动**: 旋转视角
- **右键拖动**: 平移场景
- **滚轮**: 缩放
- **中键拖动**: 调整视角倾斜

### 键盘操作
打开浏览器控制台（F12），可以使用高级命令：

```javascript
// 重播水位动画
fluidDemo.resetWaterAnimation()

// 隐藏流场
windSystem.setVisible(false)

// 显示流场
windSystem.setVisible(true)

// 更精细的参数调整
windSystem.updateOptions({
  speedFactor: 1.5,
  fadeOpacity: 0.998,
  lineWidth: 3.0
})

// 销毁流场（释放资源）
windSystem.destroy()
```

## 🎨 最佳观察角度

### 俯视角度
- 适合观察整体流场模式
- 可以看到旋涡结构
- 水体效果更明显

**设置方法**: 向上拖动鼠标（右键）至接近垂直向下

### 侧视角度  
- 适合观察地形高程变化
- 可以看到山脉和海底的剖面
- 流场的 3D 立体感更强

**设置方法**: 水平拖动鼠标调整视角

### 特写角度
- 适合观察局部细节
- 可以看清单个粒子轨迹
- 水波效果更明显

**设置方法**: 滚轮放大 + 调整视角

## ⚙️ 性能调优

## 🐛 常见问题

### Q: 页面加载很慢
A: GeoTIFF 文件较大，首次加载需要时间。检查网络连接和服务器性能。

### Q: 流场不显示
A: 
1. 等待 1-2 秒，系统会延迟初始化
2. 检查浏览器控制台是否有错误
3. 确认 Cesium-3D-Wind 文件夹中的文件完整

### Q: 性能很卡
A:
1. 降低粒子数量（控制台运行上面的"低性能设备"代码）
2. 减小轨迹长度（拖动"轨迹长度"滑块到左侧）
3. 隐藏流场，只查看地形

### Q: 流场位置不对
A: 检查 index.js 中的流场初始化参数，确保 bounds 与地形范围一致。

### Q: 想要自定义流场数据
A: 参考 `WIND_SYSTEM_README.md` 中的"替换为真实数据"章节。
